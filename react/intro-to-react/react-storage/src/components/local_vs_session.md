# Local Storage VS Session Storage

## What is the DIFFERENCE?
Local Storage : Persist even after browser tab is closed, or even afrer the entire browser is closed. Meaning it can store your login data, and the next timee you visit the same page, you will automatically be logged in.

Session Storage : It's only for that session, meaning your login data will be lost and logged out after you've closed the tab.

FOR YOUR INFOMATION : Every browser has their own storage, Chrome has it's own, Opera has it's own. Depending on which browser you are using, for example.
"Jimmy login to Facebook on Chrome, Chrome has Jimmy's login data. But when Jimmy use Facebook in Opera he has to login again, because Opera doesn't has his login data."
By this logic you can also think of it as a game saved file, you have Local Save and Cloud Save, basically the same logic! But session is a one-time-thing and a temporily saved data.
